はじめに（1回だけ）

  1. 事業所のみんなが見られる共有フォルダ（NAS、ファイルサーバー、Google ドライブや OneDrive の同期フォルダ）に、台帳用のフォルダを 1 つ作ります。例：訪問看護台帳
  2. この HTML ファイルもそのフォルダに入れておくと、全員が同じものを開けます。
  3. Chrome または Edge でこの HTML を開き、「共有フォルダを選ぶ」で 1 で作ったフォルダを選びます。（Safari と Firefox はフォルダ保存に対応していません）
  4. 右上の「あなたの名前」を入れておくと、誰がいつ更新したかが残ります。

毎日の使い方

  • 「今月のやること」で、計画書・報告書が「未作成」「作成済」「送付済」のどこまで進んだかが利用者ごとに見えます。ボタンを押すだけで今日の日付が入ります。
  • 指示書の期限が 30 日以内なら黄色、14 日以内や指示書なしは赤で表示されます。
  • 「利用者」タブで、指示書の期間や書類ファイル（PDF など）を紐づけられます。📎 を押すとファイルが開きます。
  • 他の人の変更を取り込むには「読み直す」を押します（別のタブから戻ってきたときは自動で読み直します）。

フォルダの中身

台帳は普通のファイルとして保存されるので、エクスプローラーからも見られます。バックアップはフォルダごとコピーするだけです。

気をつけること

  • 同じ利用者を 2 人が同時に編集すると、後から保存した人に「読み直しました」と出ます。もう一度操作してください。
  • 間違えて作った利用者は「終了」にするか、エクスプローラーで 利用者/ の中のフォルダごと削除してください（この画面からは消せないようにしてあります）。
  • 「お試し」モードはこのブラウザの中だけに保存され、ファイルの紐づけはできません。動きを確かめる用です。
